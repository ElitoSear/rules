# Changelog

## 0.2.0

- `no-excessive-nested-ternary`: `maxDepth` option.
- `no-iife`: `allowAsync` option.
- `no-use-effect-sync`: `allowEmptyDependencies` option.
- `prefer-tanstack-query`: `requestFunctions`, `requestClients` and `requestMethods` options, each replacing its default list.

## 0.1.0

First release: fifteen rules for React, TypeScript, Zod, TanStack Query and i18n codebases, written in TypeScript on `@typescript-eslint/utils`.
